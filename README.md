# ระบบเฝ้าระวังการบาดเจ็บแห่งชาติ (Injury Surveillance Dashboard : IS)
### โครงงานพัฒนาระบบสารสนเทศวิเคราะห์ข้อมูลระบาดวิทยาและเวชระเบียนผู้บาดเจ็บฉุกเฉิน

---

## 1. บทนำและวัตถุประสงค์ (Project Overview)
โครงการนี้จัดทำขึ้นเพื่อการศึกษาและพัฒนาแดชบอร์ดวิเคราะห์ข้อมูลสถิติผู้บาดเจ็บจากอุบัติเหตุระดับประเทศ โดยนำชุดข้อมูลเปิดภาครัฐ **ระบบเฝ้าระวังการบาดเจ็บ (Injury Surveillance: IS)** ของกรมควบคุมโรค กระทรวงสาธารณสุข มาออกแบบและพัฒนาให้อยู่ในรูปแบบระบบสารสนเทศเชิงโต้ตอบ (Interactive Data Analytics Dashboard) 

### วัตถุประสงค์หลัก:
1. เพื่อประมวลผลและแสดงผลตัวชี้วัดสำคัญทางระบาดวิทยา เช่น อัตราป่วยตาย (Case Fatality Rate : CFR), อัตราการบาดเจ็บรุนแรงที่ศีรษะ (Head Injury Rate), และความเสี่ยงสัมพัทธ์ (Relative Risk)
2. เพื่อพัฒนาระบบแดชบอร์ดที่ทำงานแบบ **Standalone Web Application** (ไฟล์เดี่ยว) สามารถทำงานได้รวดเร็วบนทุกอุปกรณ์โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ฐานข้อมูลภายนอก
3. เพื่อรองรับการนำเข้าไฟล์ข้อมูลสถิติ IS จากหลายปีพร้อมกัน (Multi-year CSV Ingestion) พร้อมระบบคัดกรองข้อมูลซ้ำซ้อนอัตโนมัติ

## 2. แหล่งที่มาของข้อมูลและมาตรฐานข้อมูล (Data Source & Standards)

* **แหล่งข้อมูล:** ศูนย์กลางข้อมูลเปิดภาครัฐ (Open Data Thailand) กรมควบคุมโรค กระทรวงสาธารณสุข  
* **ชุดข้อมูล:** `gdpublish-injury-surveillance-is` ([https://data.go.th/dataset/gdpublish-injury-surveillance-is](https://data.go.th/dataset/gdpublish-injury-surveillance-is))
* **สัญญาอนุญาต:** Open Government License (OGL-TH)
* **การคุ้มครองข้อมูลส่วนบุคคล:** เป็นชุดข้อมูลสถิติที่ผ่านการตัดข้อมูลระบุตัวตนบุคคล (De-identified Aggregate Data) ตามแนวทาง พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)
* **การจำแนกประเภทการบาดเจ็บ:** อ้างอิงตามมาตรฐานรหัสโรคสากล WHO ICD-10 (Chapter 20: External causes of morbidity and mortality)

### โครงสร้างตัวแปรสำคัญที่นำมาประมวลผล:
| ชื่อฟิลด์ | ความหมาย | ค่าที่ใช้ในการจำแนก |
| :--- | :--- | :--- |
| `prov` | จังหวัดที่เกิดเหตุ | ชื่อจังหวัด 77 จังหวัด |
| `adate` / `hdate` | วันที่เกิดเหตุ / วันที่มารับการรักษา | รูปแบบ วว/ดด/ปปปป หรือ ปปปป-ดด-วว |
| `sex` | เพศของผู้บาดเจ็บ | 1 = ชาย, 2 = หญิง |
| `age` | อายุของผู้บาดเจ็บ (ปี) | จัดกลุ่ม: เด็ก (0-14), เยาวชน (15-24), วัยทำงาน (25-59), สูงอายุ (60+) |
| `injt` | ประเภทยานพาหนะที่เกิดเหตุ | รถจักรยานยนต์, รถเก๋ง/SUV, รถปิคอัพ, รถจักรยาน, รถบรรทุก ฯลฯ |
| `injp` | บทบาทของผู้บาดเจ็บ | ผู้ขับขี่, ผู้โดยสาร, คนเดินเท้า |
| `risk1` | ปัจจัยเสี่ยงการดื่มเครื่องดื่มแอลกอฮอล์ | 1 = ดื่ม, 0 = ไม่ดื่ม |
| `risk4` | การใช้อุปกรณ์นิรภัย (หมวกกันน็อก) | 1 = สวมหมวก, 0 = ไม่สวมหมวก |
| `head_injury` | ภาวะบาดเจ็บที่ศีรษะ | 1 / HI = มีภาวะบาดเจ็บที่ศีรษะ |
| `staer` / `staward` | สถานะการจำหน่ายและผลการรักษา | จำหน่ายกลับบ้าน, Admit, ส่งต่อ, เสียชีวิต |
| `ems` | การนำส่งโรงพยาบาลด้วยระบบการแพทย์ฉุกเฉิน | ALS, BLS, FR, ILS, มาเอง/ไม่ใช้ |

## 3. สถาปัตยกรรมระบบและการออกแบบเชิงเทคนิค (System Architecture)

เพื่อแก้ปัญหาความล่าช้าในการโหลดข้อมูล CSV ขนาดใหญ่ (ชุดข้อมูลปี 2569 มีขนาดประมาณ 60 MB จำนวน 266,914 รายการ) และทำให้ผู้ใช้สามารถเปิดดูแดชบอร์ดได้ทันทีบนเว็บเบราว์เซอร์ จึงออกแบบสถาปัตยกรรมระบบเป็น **In-Memory Client-Side Architecture** ดังนี้:

```
[ is2026.csv (60 MB) ] 
       │
       ▼  (ประมวลผลล่วงหน้าด้วย Python: build_dashboard.py)
[ 8-Byte Binary Packing ] ──► [ zlib / DEFLATE Compression ] ──► [ Base64 String (~1.2 MB) ]
                                                                             │
                                                                             ▼ (ฝังลงใน index.html)
                                                              [ เบราว์เซอร์ของผู้ใช้งาน ]
                                                                             │
  ┌──────────────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────────┐
  │                                                                                                                                 │
  ▼                                          ▼                                               ▼                                      ▼
[ fflate (Decompress) ]            [ TypedArray Memory ]                             [ Bitwise Filtering ]                   [ Visual Interface ]
คลายข้อมูลสู่ Uint8Array            เก็บเคสละ 8 ไบต์ใน RAM                           ประมวลผลตัวกรองทุกมิติ                    Chart.js + SVG Map
ภายใน 100-150 ms                  (266,914 เคส ใช้เพียง ~2.1 MB)                    ภายในเวลา < 30 ms                        (Interactive UI)
```

### รายละเอียดการจัดเก็บข้อมูลระดับไบต์ (8-Byte Record Layout):
แต่ละเคสการบาดเจ็บถูกบีบอัดให้อยู่ในโครงสร้างไบต์ขนาดคงที่ 8 ไบต์ (Fixed 8-byte layout) เพื่อให้ค้นหาและกรองข้อมูลได้อย่างรวดเร็ว:
1. **Byte 0 (`pid`):** รหัสจังหวัด (0 - 76)
2. **Byte 1 (`sex`):** เพศ (1 = ชาย, 2 = หญิง)
3. **Byte 2 (`ag`):** กลุ่มอายุ (1 = เด็ก, 2 = เยาวชน, 3 = วัยทำงาน, 4 = สูงอายุ)
4. **Byte 3 (`vid`):** ประเภทยานพาหนะ (1 = จักรยานยนต์, 2 = รถยนต์, 3 = ปิคอัพ ฯลฯ)
5. **Byte 4 (`month_yr`):** รวมเดือน (Bits 0-3) และรหัสปีข้อมูล (Bits 4-7)
6. **Byte 5 (`hld_hr`):** รวมชั่วโมงเกิดเหตุ 0-23 (Bits 0-4) และรหัสเทศกาลปีใหม่/สงกรานต์ (Bits 5-6)
7. **Byte 6 (`flags1`):** แฟล็กปัจจัยเสี่ยงและผลลัพธ์ (แอลกอฮอล์, หมวกนิรภัย, บาดเจ็บศีรษะ, เสียชีวิต, Admit)
8. **Byte 7 (`flags2`):** แฟล็กระบบ EMS, สถานะ ER และบทบาทผู้บาดเจ็บ

### เทคโนโลยีที่ใช้ในการพัฒนา:
* **HTML5 / Vanilla CSS:** ออกแบบโครงสร้างและรูปลักษณ์แบบ Responsive Design ด้วยโทนสีทางการแพทย์ รองรับทั้งโหมดสว่างและโหมดมืด (Dark Mode) กำหนดขอบมนแบบ `rounded-sm` (4px)
* **JavaScript (ES6+):** ใช้ TypedArray (`Uint8Array`) สำหรับคำนวณสถิติสดในหน่วยความจำ
* **Chart.js (v4.x):** แสดงผลแผนภูมิโดนัท แท่ง และเส้น รวม 12 มิติ
* **fflate (v0.8.2):** ไลบรารีถอดรหัส zlib/DEFLATE ขนาดเล็กพิเศษที่มีประสิทธิภาพความเร็วสูงสุดบนเบราว์เซอร์
* **PapaParse (v5.4.1):** ใช้สำหรับการนำเข้าไฟล์ CSV ใหม่แบบแบ่งชิ้นข้อมูล (Chunk Ingestion)
* **SVG Vector Mapping:** สร้างแผนที่ความร้อน (Choropleth Map) ของประเทศไทย 77 จังหวัดจากพิกัด GeoJSON โดยตรง ไม่ต้องพึ่งพา Map Tile ภายนอก

## 4. คุณสมบัติและความสามารถของระบบ (Dashboard Capabilities)

1. **การวิเคราะห์ทางระบาดวิทยาขั้นสูง:**
   * คำนวณอัตราป่วยตาย **Case Fatality Rate (CFR)** และอัตราการรับไว้รักษาในโรงพยาบาล (Admit Rate)
   * คำนวณค่า **Relative Risk (RR)** เพื่อเปรียบเทียบความเสี่ยงของการไม่สวมหมวกนิรภัยต่อการบาดเจ็บที่ศีรษะ
   * วิเคราะห์ช่วงเวลาเกิดเหตุสูงสุดรายชั่วโมง (Hourly Peak) และสถิติเปรียบเทียบช่วง 7 วันอันตราย (ปีใหม่ และ สงกรานต์)
2. **ระบบแผนที่ความรุนแรง 77 จังหวัด (Interactive Thailand Choropleth Map):**
   * แสดงระดับความรุนแรงตามระดับเฉดสีความร้อน (Heatmap Gradient)
   * แสดงรายละเอียดรายจังหวัดเมื่อวางเมาส์ (Hover Tooltip) และสามารถคลิกที่จังหวัดเพื่อกรองข้อมูลทั้งหน้าได้ทันที
3. **ระบบนำเข้าข้อมูลแบบหลายไฟล์ (Multi-File / Multi-Year Import):**
   * สามารถเลือกนำเข้าไฟล์ CSV พร้อมกันหลายปี (เช่น `is2018.csv` จนถึง `is2026.csv`)
   * มีระบบ **Smart Fingerprint Deduplication** ตรวจจับเคสซ้ำซ้อนจากข้อมูลเวชระเบียน เพื่อป้องกันการนับข้อมูลซ้ำ
4. **ระบบตรวจจับปีและช่วงเวลาอัตโนมัติ (Temporal Normalization):**
   * รองรับการแปลงปีระหว่าง พุทธศักราช (พ.ศ.) และ คริสต์ศักราช (ค.ศ.) อัตโนมัติ แสดงผลควบคู่กันอย่างชัดเจน เช่น `พ.ศ. 2561 (ค.ศ. 2018)`
   * ป้ายชื่อรายงานวิชาการจะปรับเปลี่ยนตามช่วงเวลาของข้อมูลที่นำเข้าจริง
5. **ระบบพิมพ์รายงานทางวิชาการ (Print / PDF View):**
   * มีรูปแบบ Print Media Stylesheet สำหรับจัดหน้ารายงานเพื่อการนำเสนอหรือบันทึกเป็น PDF

## 5. ขั้นตอนการติดตั้งและเปิดใช้งานในเครื่อง (Local Setup)

1. ดาวน์โหลดหรือ Clone โฟลเดอร์โปรเจกต์นี้
2. สามารถดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Firefox, Safari) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเซิร์ฟเวอร์
3. หากต้องการคอมไพล์หรือสร้างไฟล์แดชบอร์ดใหม่จากชุดข้อมูล CSV:
   ```bash
   python build_dashboard.py
   ```

## 6. ขั้นตอนการนำขึ้น Public Link ด้วย GitHub Pages (อย่างละเอียด)

เนื่องจากระบบได้รับการออกแบบเป็นไฟล์เดี่ยวแบบสมบูรณ์ในตัวเอง (`index.html`) การนำขึ้นโฮสต์บน **GitHub Pages** จึงทำได้สะดวกรวดเร็วและฟรีตลอดการใช้งาน ตามขั้นตอนดังนี้:

### ขั้นตอนที่ 1: ตรวจสอบและสร้าง Git Repository ในเครื่อง
เปิดโปรแกรม **PowerShell** หรือ **Terminal** แล้วเข้าไปยังโฟลเดอร์ของโปรเจกต์ (`d:\freelance\isdata`):
```bash
# 1. สร้าง Git Repository
git init

# 2. เพิ่มไฟล์ทั้งหมดเข้าสู่การติดตาม (โฟลเดอร์ data/ จะถูกข้ามอัตโนมัติตาม .gitignore)
git add .

# 3. บันทึกประวัติไฟล์ (Commit)
git commit -m "Initial release of Injury Surveillance Dashboard"
```

### ขั้นตอนที่ 2: สร้าง Repository ใหม่บน GitHub
1. เข้าเว็บไซต์ [https://github.com](https://github.com) และลงชื่อเข้าใช้งาน
2. ตรวจสอบ Repository: [https://github.com/kamalasai/isdata](https://github.com/kamalasai/isdata)
3. ตรวจสอบให้แน่ใจว่าสถานะเป็น **Public** (เพื่อให้เปิดดูผ่านอินเทอร์เน็ตได้)

### ขั้นตอนที่ 3: เชื่อมต่อและ Push โค้ดขึ้น GitHub
รันคำสั่งใน PowerShell เพื่อส่งไฟล์ขึ้น Repository:
```bash
# ตั้งชื่อ Branch หลักเป็น main
git branch -M main

# ผูกเครื่องเข้ากับ Remote Repository บน GitHub
git remote add origin https://github.com/kamalasai/isdata.git

# ส่งไฟล์ขึ้น GitHub
git push -u origin main
```

### ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages
1. ในหน้า [https://github.com/kamalasai/isdata/settings/pages](https://github.com/kamalasai/isdata/settings/pages)
2. ที่ส่วน **Build and deployment**:
   * **Source:** ให้เลือกเป็น `Deploy from a branch`
   * **Branch:** เลือกเป็น `main` และโฟลเดอร์ให้เลือก `/ (root)`
3. คลิกปุ่ม **Save**
4. รอระบบประมวลผลประมาณ 1-2 นาที เมื่อรีเฟรชหน้าจะปรากฏข้อความแถบสีเขียวพร้อมลิงก์:
   > 🚀 **Public URL:** [https://kamalasai.github.io/isdata/](https://kamalasai.github.io/isdata/)
5. สามารถนำ URL นี้ไปเปิดดูผ่านมือถือ แท็บเล็ต หรือส่งให้อาจารย์ตรวจงานได้ทันที
